This page is the published TypeScript client for the consumer marketplace at `https://mcp.securelend.ai/mcp`. Underwriting is the [Lender MCP](/mcp/lender).

`npm install @securelend/sdk` resolves to `0.1.0-beta.5` on the npm registry. That is the package these snippets use. The SecureLend/sdk git branch is ahead of that tarball. See [SDK overview](/sdk/overview).

There is no public price. [Start a 7-day trial](https://securelend.ai/login?trial=1) or [talk to us](https://securelend.ai/contact).

## Install

```bash
npm install @securelend/sdk
```

## Compare business loans

`compareBusinessLoans` takes `loanAmount` and `purpose`. `annualRevenue`, `industry`, and `state` are optional. The type has no `creditScore` field. The client does not require an `apiKey`.

This snippet typechecks against `@securelend/sdk@0.1.0-beta.5`. It was not executed against the live server.

```typescript
import { SecureLend } from "@securelend/sdk";

const client = new SecureLend();

const result = await client.compareBusinessLoans({
  loanAmount: 200000,
  purpose: "equipment",
  annualRevenue: 1200000,
  industry: "technology",
  state: "CA",
});

const count = result.summary.totalOffers;
const first = result.offers[0];
const apr = first && first.terms.interestRate.apr;
```

`result.offers` is an array of `LoanOffer`. A rate lives at `terms.interestRate.apr`, not on a flat `interestRate` field. The full method list is the [JavaScript reference](/sdk/javascript).

The live marketplace `tools/list` schema for `compare_business_loans` is an open object. It does not list these fields as required. The SDK type is stricter than that schema.
