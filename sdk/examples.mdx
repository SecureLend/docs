These snippets typecheck against `@securelend/sdk@0.1.0-beta.5`. They were not executed against `https://mcp.securelend.ai/mcp`.

The older `getLoanOffers` helper, a constructor field named `timeout` or `retries`, and `creditScore` on `compareBusinessLoans` are not in that package.

## Business loans

```typescript
import { SecureLend } from "@securelend/sdk";

const client = new SecureLend();

const result = await client.compareBusinessLoans({
  loanAmount: 200000,
  purpose: "equipment",
  annualRevenue: 1200000,
});

if (result.offers.length > 0) {
  const offer = result.offers[0];
  const apr = offer.terms.interestRate.apr;
  const termMonths = offer.terms.termMonths;
  console.log(result.summary.totalOffers, apr, termMonths);
}
```

## Loan payment

```typescript
import { SecureLend } from "@securelend/sdk";

const client = new SecureLend();

const payment = await client.calculateLoanPayment({
  loanAmount: 200000,
  interestRate: 7.5,
  loanTermInMonths: 60,
});

console.log(
  payment.monthlyPayment,
  payment.totalPayment,
  payment.totalInterest,
);
```

## Personal loans

`purpose` is an enum on this method. `creditScore` is optional here, and only here among the two loan examples.

```typescript
import { SecureLend } from "@securelend/sdk";

const client = new SecureLend({
  serverUrl: "https://mcp.securelend.ai/mcp",
});

const personal = await client.comparePersonalLoans({
  loanAmount: 25000,
  purpose: "debt_consolidation",
  creditScore: 720,
});

console.log(personal.summary.totalOffers);
```

More fields are on the [JavaScript reference](/sdk/javascript).
