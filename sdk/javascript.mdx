This page is `@securelend/sdk@0.1.0-beta.5`, the package `npm install @securelend/sdk` installs. It is not the `0.2.0-beta.0` git tree. See [SDK overview](/sdk/overview).

Parameter lists below are the published TypeScript types. On the live marketplace `tools/list`, 18 of 20 tools advertise an open object (`additionalProperties: true`) with no `properties` and no `required` list. That includes the comparison and calculator tools and also `display_offer_form`, `track_offer_status`, `display_upload_documents_form`, and `submit_documents`. Only `get_offer` and `get_multiple_offers` publish `properties`, and both require `applicant`. The SDK types are stricter than those live schemas. No tool was called.

`new SecureLend()` uses `https://mcp.securelend.ai/mcp` when `serverUrl` is omitted. `apiKey` is optional and is not attached as an `Authorization` header by the published transport.

## Loan comparison

Each method returns `LoanComparisonResponse`: `offers` (`LoanOffer[]`), `summary` (`totalOffers`, `bestRate`, optional `bestApprovalProbability`, optional `fastestFunding`), optional `searchCriteria`, `metadata` (`queryId`, `timestamp`, optional `sessionId`), and optional `widget`.

A `LoanOffer` has `offerId`, `lender` (`id`, `name`, `type`, optional `logoUrl`), `product` (`name`, `type`, optional `description`), `terms`, optional `fees`, optional `matching`, optional `process`, optional `lenderInfo` (string), optional `badges` (string array), and optional `isSecureLendTenant` (boolean).

`terms.interestRate` is `{ type: "fixed" | "variable"; apr: number; rate?: number }`. `terms.amount` is money: `{ amount: number; currency?: string }` with `currency` length 3 when present. `terms.termMonths` is an integer. `terms.payment` is `{ frequency?: string; amount: money }`. `terms.totalCost` is optional money. `terms.repayment` is optional `{ totalRepaymentAmount: number; costOfFinancing: number }`.

`fees`, when present, has optional `origination`. That object has optional `amount` (money) and optional `percentage` (number).

`matching`, when present, has optional `approvalProbability` (0 to 1), optional `matchScore` (0 to 100), and optional `matchReasons` (string array).

`process`, when present, requires `applicationMethod` (string) and may include `applicationUrl` and `fundingSpeed.description`.

There is no `lenderName`, flat `interestRate` number, `monthlyPayment`, or `approvalLikelihood` field on `LoanOffer`.

### comparePersonalLoans

Required: `loanAmount` (SDK schema minimum 1000, maximum 100000), `purpose` (`debt_consolidation`, `home_improvement`, `major_purchase`, `medical`, `vacation`, `other`).

Optional: `creditScore`, `monthlyIncome`, `employmentStatus` (`employed`, `self_employed`, `retired`, `unemployed`), `state`.

### compareBusinessLoans

Required: `loanAmount` (SDK schema minimum 1000), `purpose` (string).

Optional: `annualRevenue`, `industry`, `state`.

`creditScore` is not on this type.

### comparePersonalMortgages and compareBusinessMortgages

Both take `MortgageSearchParams`.

Required: `loanAmount` (SDK schema minimum 50000, maximum 2000000), `loanType` (`conventional`, `fha`, `va`, `jumbo`, `refinance`).

Optional: `homePrice`, `downPayment`, `creditScore`, `propertyType` (`primary`, `secondary`, `investment`), `state`.

### compareCarLoans

Required: `loanAmount` (SDK schema minimum 1000, maximum 100000), `isNew` (boolean).

Optional: `creditScore`, `state`.

### compareStudentLoans

Required: `loanAmount` (SDK schema minimum 1000, maximum 250000), `degreeType` (`undergraduate`, `graduate`, `mba`, `medical`, `law`).

Optional: `creditScore`, `coSignerCreditScore`, `state`.

## Banking and cards

### compareBusinessBanking

Optional: `industry`, `monthlyTransactions`. Returns `offers` of `accountId`, `name`, `issuer`, `imageUrl`, `rating`, `bestFor`, `apy`, optional `interestRate`, `monthlyFee`, `bonus`, plus optional `searchCriteria`, `metadata`, and optional `widget`.

### comparePersonalBanking

Optional: `features` (string array). Offer fields add `overdraftRating`.

### compareSavingsAccounts

Optional: `initialDeposit`. Offer fields include `minBalanceForApy` and `monthlyFee`.

### compareBusinessCreditCards

All fields are optional. `creditScore` is 300 to 850. `annualRevenue` minimum is 0. `businessAgeInYears` minimum is 0.

Returns `BusinessCreditCardComparisonResponse`: `offers`, optional `searchCriteria`, `metadata` (`queryId`, `timestamp`, optional `sessionId`), optional `widget`.

Each offer has `cardId`, `name`, `issuer`, `imageUrl`, `rating` (0 to 5), `creditScoreRange`, `welcomeBonus`, and `terms`. `terms.apr` and `terms.annualFee` are numbers. `terms.creditLimit` is money (`amount`, optional `currency` of length 3).

### comparePersonalCreditCards

All fields are optional. `creditScore` is 300 to 850. `rewardsType` is `cash_back`, `travel`, or `points`.

Returns `PersonalCreditCardComparisonResponse` with the same wrapper as the business card response: `offers`, optional `searchCriteria`, `metadata`, optional `widget`.

Each offer has `cardId`, `name`, `issuer`, `imageUrl`, `rating` (0 to 5), `bestFor`, `rewardsRate`, `introOffer`, `recommendedCreditScore`, `terms`, and optional `applicationUrl`. `terms.apr.purchase` and `terms.apr.balanceTransfer` are numbers. `terms.apr.penalty` is optional. `terms.fees.annual` is a number.

## Calculators

### calculateLoanPayment

Required: `loanAmount`, `interestRate`, `loanTermInMonths`.

Returns `monthlyPayment`, `totalPayment`, `totalInterest`, and optional `widget`.

### calculateMortgagePayment

Required: `propertyValue`, `downPayment`, `interestRate`, `loanTermInYears`, `propertyTaxRate`, `homeInsurance`.

Returns `loanAmount`, `principalAndInterest`, `monthlyPropertyTax`, `monthlyHomeInsurance`, `totalMonthlyPayment`, and optional `widget`.

### compareLeaseVsPurchase

Required on the SDK input type: `purchasePrice`, `downPayment`, `loanTermInMonths`, `interestRate`, `salesTaxRate`, `leaseTermInMonths`, `monthlyLeasePayment`, `moneyFactor`, `residualValuePercentage`, `expectedOwnershipInMonths`.

`acquisitionFee` and `securityDeposit` default to 0.

Returns `purchaseAnalysis`, `leaseAnalysis`, `comparison`, and optional `widget`.

## Applications

These TypeScript types do not match the live `tools/list` schema field for field. `get_offer` and `get_multiple_offers` on the live server require `applicant` (`firstName`, `lastName`, `email`, optional `phone`) and also accept fields such as `confirmed`, `amount`, `product`, and `lender`. The SDK types below were not called.

### getOffer

Required by the SDK type: `productType`, `applicant` (`firstName`, `lastName`, `email`, optional `phone`), `applicationData`, `provider` (`providerId`, `providerName`).

`productType` is one of `INSTALLMENT_LOAN`, `LINE_OF_CREDIT`, `SHORT_TERM_CREDIT`, `BNPL`, `MORTGAGE`, `AUTO_LOAN`, `AUTO_REFINANCE`, `STUDENT_LOAN`, `STUDENT_LOAN_REFINANCE`, `BUSINESS_LOAN`, `BUSINESS_BANKING`, `BUSINESS_CREDIT_CARD`, `PERSONAL_BANKING`, `SAVINGS_ACCOUNT`, `PERSONAL_CREDIT_CARD`.

Returns `PersonalApplication` (`id`, `createdAt`, `updatedAt`, `applicationType`, `productType`, `status`, `applicant`, `applicationData`, `providers`, `email`, optional `widget`).

### getMultipleOffers

Same applicant and `productType`, plus `applicationData` and `providers` (at least one `{ providerId, providerName }` on the SDK schema). Returns the same `PersonalApplication`.

### displayOfferForm

Optional: `sessionId`, `offerId`.

Returns `DisplayOfferFormResponse`: `offer` and `allOffers` (each item is a loan, business card, business banking, personal banking, savings, or personal card offer), `applicationData` (object that allows extra keys), `productType` (string), optional `widget`.

### trackOfferStatus

The SDK schema requires `applicationId` or `email`.

Returns `TrackOfferStatusResponse`: `applications` (`PersonalApplication[]`) and optional `widget`.

### displayUploadDocumentsForm

Optional: `applicationId`.

Returns `DisplayUploadDocumentsFormResponse`: optional `widget` only.

### submitDocuments

Required by the SDK type: `applicationId`, `fileName`, `documentType`. Optional `_openai_meta`.

`documentType` is one of `articles-of-incorporation`, `balance-sheet`, `bank-statement`, `business-license`, `business-plan`, `contract`, `drivers-license`, `financial-statement`, `identity-document`, `invoice`, `lease-agreement`, `other-business-document`, `other-personal-document`, `passport`, `profit-and-loss-statement`, `proof-of-address`, `proof-of-income`, `property-document`, `purchase-order`, `tax-return`, `utility-bill`, `vehicle-document`, `voided-check`.

Returns `SubmitDocumentsResponse`: `success` (boolean), `message` (string), optional `uploadUrl`, optional `uploadFields` (record of string to string), optional `documentId`, optional `widget`.

## Adapters and application DTOs

Each adapter interface has `readonly name: string` and a `search` method.

- `PersonalLenderAdapter`, `BusinessLenderAdapter`, `MortgageLenderAdapter`, `AutoLenderAdapter`, and `StudentLenderAdapter` return `LoanOffer[]`.
- `BusinessCreditCardAdapter` returns `BusinessCreditCardOffer[]`. `PersonalCreditCardAdapter` returns `PersonalCreditCardOffer[]`.
- `BusinessBankingAdapter` search accepts the business banking search fields plus optional `maxResults` and `includeReviewStatus`. It returns `BusinessBankingOffer[]`.
- `PersonalBankingAdapter` returns `PersonalBankingOffer[]`. `SavingsAdapter` returns `SavingsOffer[]`.

`CreatePersonalApplicationDTO` is `productType`, `applicant` (`firstName`, `lastName`, `email`, optional `phone`), `applicationData`, and optional `providers` (`providerId`, `providerName`).

`CreateBusinessApplicationDTO` uses the same `productType`, `applicationData`, and optional `providers`. Its `applicant` is `businessName`, optional `ein`, and `contact` (the personal applicant fields).

## Client

`connect()`, `enableDebug()`, `disableDebug()`, and `setApiKey(apiKey: string)` are on the class. `setApiKey` updates the stored key and marks the MCP client disconnected. The next call constructs a new transport from the URL only.

`client.mcp` is a public readonly field. It is the `Client` from `@modelcontextprotocol/sdk` (`name` `@securelend/sdk`, `version` `1.0.0`). The constructor assigns `this.mcp` from the inner transport.

Every method goes through `callTool`, which returns the parsed object plus `widget`. `getWidget` sets `widget` to the `text` of a content resource whose mime type is `text/html`. If that resource is absent, `widget` is `undefined`. Every published response schema includes optional `widget` as a string.

`parseJsonResponse` uses `structuredContent` when it is present. Otherwise it takes the first content item that is an `application/json` resource or a `text` item, then `JSON.parse`s that text. `schema.parse` runs on the resulting value.

The published `package.json` sets `engines.node` to `>=16.0.0`. This page does not claim a browser, edge, or React Server Components runtime. The client does rewrite a `serverUrl` that starts with `/` when `window` is defined. That branch was not run in a browser.

## Errors

Exported classes in this version: `SecureLendError`, `AuthenticationError`, `RateLimitError`, `ValidationError`, `NotFoundError`, `NetworkError`, `ServerError`.

The published client throws `AuthenticationError` when a connection error message contains `401`, and `NetworkError` for other connection failures.

`ValidationError` is thrown in two places in `dist/index.js`. If `schema.parse` throws a `ZodError`, the client throws `ValidationError` with message `Invalid response from MCP server: failed to validate JSON content`. The inner `callTool` throws `ValidationError` (`Invalid tool arguments`) when a caught error message contains `400`.

A tool result with no `structuredContent` and no `text` or `application/json` content item, a `JSON.parse` failure, or an invalid content structure is caught and rethrown as `SecureLendError` with type `mcp_error` and message `Invalid response from MCP server: failed to parse JSON content`. Other tool failures become `SecureLendError` with type `mcp_tool_error`.

`RateLimitError`, `NotFoundError`, and `ServerError` are exported and are not constructed in the published `dist/index.js`. There is no retry loop and no published requests-per-minute figure. `signOutcomePayload`, `FeatureDisabledError`, `ConsentRequiredError`, and `InvalidTransitionError` are not in this tarball. See [Webhooks](/api/webhooks).
