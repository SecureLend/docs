This page is `@securelend/sdk@0.1.0-beta.5`, the package `npm install @securelend/sdk` installs. It is not the `0.2.0-beta.0` git tree. See [SDK overview](/sdk/overview).

Parameter lists below are the published TypeScript types. The live marketplace `tools/list` schema for the comparison and calculator tools is an open object with no `properties` and no `required` list. The SDK types are stricter than that live schema. No tool was called.

`new SecureLend()` uses `https://mcp.securelend.ai/mcp` when `serverUrl` is omitted. `apiKey` is optional and is not attached as an `Authorization` header by the published transport.

## Loan comparison

Each method returns `LoanComparisonResponse`: `offers` (`LoanOffer[]`), `summary` (`totalOffers`, `bestRate`, optional `bestApprovalProbability`, optional `fastestFunding`), optional `searchCriteria`, and `metadata` (`queryId`, `timestamp`, optional `sessionId`).

A `LoanOffer` has `offerId`, `lender` (`id`, `name`, `type`, optional `logoUrl`), `product` (`name`, `type`, optional `description`), `terms`, optional `fees`, optional `matching`, and optional `process`. `terms.interestRate` is `{ type: "fixed" | "variable"; apr: number; rate?: number }`. `terms.amount` and `terms.payment.amount` are `{ amount: number; currency?: string }`. `terms.termMonths` is a number.

`matching.approvalProbability` is optional, from 0 to 1 on the SDK schema. There is no `lenderName`, `interestRate` number, `monthlyPayment`, or `approvalLikelihood` field on `LoanOffer`.

### comparePersonalLoans

Required: `loanAmount` (SDK schema minimum 1000, maximum 100000), `purpose` (`debt_consolidation`, `home_improvement`, `major_purchase`, `medical`, `vacation`, `other`).

Optional: `creditScore`, `monthlyIncome`, `employmentStatus` (`employed`, `self_employed`, `retired`, `unemployed`), `state`.

### compareBusinessLoans

Required: `loanAmount` (SDK schema minimum 1000), `purpose` (string).

Optional: `annualRevenue`, `industry`, `state`.

`creditScore` is not on this type.

### comparePersonalMortgages and compareBusinessMortgages

Both take `MortgageSearchParams`.

Required: `loanAmount` (SDK schema minimum 50000, maximum 2000000), `loanType` (`conventional`, `fha`, `va`, `jumbo`, `refinance`).

Optional: `homePrice`, `downPayment`, `creditScore`, `propertyType` (`primary`, `secondary`, `investment`), `state`.

### compareCarLoans

Required: `loanAmount` (SDK schema minimum 1000, maximum 100000), `isNew` (boolean).

Optional: `creditScore`, `state`.

### compareStudentLoans

Required: `loanAmount` (SDK schema minimum 1000, maximum 250000), `degreeType` (`undergraduate`, `graduate`, `mba`, `medical`, `law`).

Optional: `creditScore`, `coSignerCreditScore`, `state`.

## Banking and cards

### compareBusinessBanking

Optional: `industry`, `monthlyTransactions`. Returns `offers` of `accountId`, `name`, `issuer`, `imageUrl`, `rating`, `bestFor`, `apy`, optional `interestRate`, `monthlyFee`, `bonus`, plus optional `searchCriteria` and `metadata`.

### comparePersonalBanking

Optional: `features` (string array). Offer fields add `overdraftRating`.

### compareSavingsAccounts

Optional: `initialDeposit`. Offer fields include `minBalanceForApy` and `monthlyFee`.

### compareBusinessCreditCards

Optional: `creditScore`, `annualRevenue`, `businessAgeInYears`.

### comparePersonalCreditCards

Optional: `creditScore`, `rewardsType` (`cash_back`, `travel`, `points`).

## Calculators

### calculateLoanPayment

Required: `loanAmount`, `interestRate`, `loanTermInMonths`.

Returns `monthlyPayment`, `totalPayment`, `totalInterest`.

### calculateMortgagePayment

Required: `propertyValue`, `downPayment`, `interestRate`, `loanTermInYears`, `propertyTaxRate`, `homeInsurance`.

Returns `loanAmount`, `principalAndInterest`, `monthlyPropertyTax`, `monthlyHomeInsurance`, `totalMonthlyPayment`.

### compareLeaseVsPurchase

Required on the SDK input type: `purchasePrice`, `downPayment`, `loanTermInMonths`, `interestRate`, `salesTaxRate`, `leaseTermInMonths`, `monthlyLeasePayment`, `moneyFactor`, `residualValuePercentage`, `expectedOwnershipInMonths`.

`acquisitionFee` and `securityDeposit` default to 0.

Returns `purchaseAnalysis`, `leaseAnalysis`, and `comparison`.

## Applications

These TypeScript types do not match the live `tools/list` schema field for field. `get_offer` and `get_multiple_offers` on the live server require `applicant` (`firstName`, `lastName`, `email`, optional `phone`) and also accept fields such as `confirmed`, `amount`, `product`, and `lender`. The SDK types below were not called.

### getOffer

Required by the SDK type: `productType`, `applicant` (`firstName`, `lastName`, `email`, optional `phone`), `applicationData`, `provider` (`providerId`, `providerName`).

`productType` is one of `INSTALLMENT_LOAN`, `LINE_OF_CREDIT`, `SHORT_TERM_CREDIT`, `BNPL`, `MORTGAGE`, `AUTO_LOAN`, `AUTO_REFINANCE`, `STUDENT_LOAN`, `STUDENT_LOAN_REFINANCE`, `BUSINESS_LOAN`, `BUSINESS_BANKING`, `BUSINESS_CREDIT_CARD`, `PERSONAL_BANKING`, `SAVINGS_ACCOUNT`, `PERSONAL_CREDIT_CARD`.

Returns `PersonalApplication` (`id`, `createdAt`, `updatedAt`, `applicationType`, `productType`, `status`, `applicant`, `applicationData`, `providers`, `email`).

### getMultipleOffers

Same applicant and `productType`, plus `applicationData` and `providers` (at least one `{ providerId, providerName }` on the SDK schema).

### displayOfferForm

Optional: `sessionId`, `offerId`.

### trackOfferStatus

The SDK schema requires `applicationId` or `email`.

### displayUploadDocumentsForm

Optional: `applicationId`.

### submitDocuments

Required by the SDK type: `applicationId`, `fileName`, `documentType`. Optional `_openai_meta`.

`documentType` is one of `articles-of-incorporation`, `balance-sheet`, `bank-statement`, `business-license`, `business-plan`, `contract`, `drivers-license`, `financial-statement`, `identity-document`, `invoice`, `lease-agreement`, `other-business-document`, `other-personal-document`, `passport`, `profit-and-loss-statement`, `proof-of-address`, `proof-of-income`, `property-document`, `purchase-order`, `tax-return`, `utility-bill`, `vehicle-document`, `voided-check`.

## Client methods

`connect()`, `enableDebug()`, `disableDebug()`, and `setApiKey(apiKey: string)` are on the class. `setApiKey` updates the stored key and marks the MCP client disconnected. The next call constructs a new transport from the URL only.

The published `package.json` sets `engines.node` to `>=16.0.0`. This page does not claim a browser, edge, or React Server Components runtime. The client does rewrite a `serverUrl` that starts with `/` when `window` is defined. That branch was not run in a browser.

## Errors

Exported classes in this version: `SecureLendError`, `AuthenticationError`, `RateLimitError`, `ValidationError`, `NotFoundError`, `NetworkError`, `ServerError`.

The published MCP client throws `AuthenticationError` when a connection error message contains `401`, `NetworkError` for other connection failures, `ValidationError` when a tool error message contains `400` or the JSON fails the response schema, and `SecureLendError` for other tool failures. `RateLimitError`, `NotFoundError`, and `ServerError` are exported and are not constructed in the published `dist/index.js`. There is no retry loop and no published requests-per-minute figure.
