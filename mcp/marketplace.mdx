This is not the underwriting server. Underwriting is the [Lender MCP](/mcp/lender).

**URL:** `https://mcp.securelend.ai/mcp`

SecureLend, Inc. is a US (Delaware) company. This URL is a consumer marketplace. It compares loans, cards, and bank accounts, and it can submit a lending enquiry. It does not expose the 11 lender tools.

Checked on 15 October 2026. No tool was called.

- `initialize` returned protocol `2025-03-26` and server info `securelend` version `1.0.0`.
- `tools/list` without a bearer token returned the 20 tools below.
- GET returned 404 and `{"error":"not_found"}`. A browser visit is not an MCP session.

The 14 comparison and calculator tools advertise `inputSchema` as `{ "type": "object", "additionalProperties": true }` with no `properties` and no `required` list. `get_offer` and `get_multiple_offers` require `applicant`.

The published TypeScript client is [SDK overview](/sdk/overview). Its types are stricter than those live schemas, and `getOffer` uses different field names. No marketplace tool was called.

### get_offer

Create and submit a user-confirmed lending enquiry to one selected lender and return the created application record and next-step details. Collect the applicant's first name, last name, and email before submitting. Phone is optional.

### get_multiple_offers

Create and submit a user-confirmed lending enquiry to multiple selected lenders and return the created application record and routing details. Collect the applicant's first name, last name, and email before submitting. Phone is optional.

### display_offer_form

Retrieve a cached offer and show a pre-filled enquiry review form before user confirmation.

### track_offer_status

Retrieve the status of previously submitted SecureLend enquiries by application ID or applicant email.

### display_upload_documents_form

Display a form that lets users upload supporting documents for an existing application.

### submit_documents

Generate a presigned upload URL and create document metadata for an application in SecureLend storage.

`get_offer`, `get_multiple_offers`, and `submit_documents` describe writes. They were not called.
