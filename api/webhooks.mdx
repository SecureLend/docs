title: Webhooks
---

`@securelend/sdk@0.1.0-beta.5` does not export webhook helpers.

The default branch of SecureLend/sdk exports `verifyWebhook`, `parseEvent`, and `signWebhook` from `packages/sdk/src/webhooks.ts`, and a `WebhookSignatureError` class. That code is in package version `0.2.0-beta.0`, which is not the published tarball. Signing and verification behavior was not executed for this page.
