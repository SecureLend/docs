This page does not describe a loans HTTP API.

No loans route was found in the public SecureLend/securelend repository. `https://github.com/orgtom78/securelend-platform` could not be read.

The published npm package `@securelend/sdk@0.1.0-beta.5` calls marketplace tools over MCP. It does not ship a loans REST client. Git history on SecureLend/sdk includes REST paths such as `/v1/placement/enquiries` in `packages/sdk/src/contract.ts` on the default branch (`0.2.0-beta.0`). Those methods are not in the published tarball, and they were not called.
