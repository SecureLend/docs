SecureLend, Inc. is a US (Delaware) company. Two public surfaces are documented here:

- Underwriting MCP: [Lender MCP](/mcp/lender), `https://mcp.securelend.ai/v1/lender/mcp`
- Consumer marketplace MCP and the published TypeScript client: [SDK overview](/sdk/overview)

The public [SecureLend/securelend](https://github.com/SecureLend/securelend) repository defines ops routes such as `/api/v1/agents`, `/api/v1/approvals`, `/api/v1/costs`, `/api/v1/kpis/sources`, and `/api/v1/finance/overview` in `packages/ops-cdk/src/lambdas/api.ts`. It does not define a public loans-offer HTTP API in that file.

`https://github.com/orgtom78/securelend-platform` could not be read from this environment (the repository was not found). Claims about live API routes in that repository are not made on this page.

An offer-matching flowchart, a sandbox of synthetic data, and encryption guarantees used to be stated here. They are not restated, because those details were not found in the public code that was read.
